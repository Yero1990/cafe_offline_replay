

Steps
1.) You need the header files "Bins.h" which is where I declare my binning for MF and SRC histograms, "Cuts.h" which has functions to apply cuts and the cut values themselves, "Histo.h" which makes it easier to declare histograms for data and simulation, and the files I used from Carlos Yero "hist_utils.h" and "parse_utils.h" which are useful for writing the information from a root histogram to a .csv or .xlsv file.

2.) Set up the appropriate file structure OR change the pathing in the "omniSkims.C", "analysisbash.sh", and "ratiohistos.C" codes as needed. In "omniSkims.C" look to lines 258->272, 279->310, 1834->1964, 2006->2041, 2256->2376, and 2414->2514 for the pathing. In "ratiohistos.C" look to lines like 193 at the start of each target's block of code where I path from the location of "ratiohistos.C" to a .root file. 

3.) Execute "analysisbash.sh" by entering "./analysisbash.sh" for MF and then SRC by running "omniSkims.C" which creates a .root files and .png files

4.) Execute "ratiohistos.C" to generate per-proton normalized .csv files. "ratiohistos.C" reads in from the .root files generated by "omniSkims.C. Move the generated .csv files to an appropriate location. This file finalizes the normalization. While "omniSkims.C" takes into account proton efficiency and detector efficiency, "ratiohistos.C" applies scaling and corrections for oil contamination, target istropic purity, total charge, radiative corrections, nuclear transparency, areal density/target thickness, and per-proton or per-nuclues scaling.

5.) Change the block comments (lines 1427-1753 and 1758-2066) in "ratiohistos.C" to per-nucleus normalization

6.) Execute "ratiohistos.C" to generate per-nucleus normalized .csv files. Move the .csv files to an appropriate location

7.) In the same folder as the appropriate .csv files run ["plot_var1pp.py" and "plot_var2pp.py"] OR ["plot_paperpn.py", "plot_var2pn.py", "plot_var1pn.py", and "plot_triplet.py"] to produce nice histograms


I have also included abslh2.C which is my code that does the absolute hydrogen cross-section analysis. Again, the pathways to the correct files will need to be adjusted depending on the "local" file structure.
